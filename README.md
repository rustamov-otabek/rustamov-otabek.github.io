Otabek Rustamov — Personal Portfolio
Personal portfolio site. Economics student (TSUE), accountant, and developer of personal AI/automation projects (JARVIS, NEXORA).
Stack
HTML5 / CSS3 (custom properties, grid, flexbox)
Vanilla JavaScript
Three.js — procedural 3D hero object (reacts to mouse + scroll)
Client-side EN/RU localization (no page reload)
Accessible: respects `prefers-reduced-motion`, responsive from mobile to desktop
Structure
```
index.html   — markup, content, sections
style.css    — layout, theme, animations
script.js    — i18n, scroll reveal, project tilt, Three.js hero scene
```
Run locally
Just open `index.html` in a browser — no build step required.
